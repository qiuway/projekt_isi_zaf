# FoodFlow - React + TypeScript

Projekt zawiera wyłącznie frontendowe makiety ekranów:
- logowanie,
- rejestracja,
- strona główna,
- restauracja,
- koszyk,
- profil,
- ustawienia.

W projekcie nie ma logiki biznesowej ani backendu. Są tylko przejścia między ekranami i puste/przykładowe przyciski.

## Uruchomienie

```bash
npm install
npm run dev
```

## Technologie

- React
- TypeScript
- Vite
